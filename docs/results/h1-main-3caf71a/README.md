# h1 main experiment

The h1 pilot/main sample contains two task pairs with two independent specialists per task. Both pairs passed candidate qualification and official grading. E0 and E1 selected the same candidate and received identical official scores in both tasks; E2 misbound evidence was evaluated as a negative control.

Conclusion: no positive E1 treatment effect was observed in this h1 sample. The result is valid and not an infrastructure failure. The code/data provenance is tied to GitHub commit `3caf71a`.
