# Experiment status

## Current scope

The study is frozen to the early agent-pool expansion stages h1–h3: 2, 5, and 8 specialists. h4–h6 are outside scope because the platform does not currently provide the required stage-specific bundles.

## Validity rules

A cell enters the main table only when candidate identity, provenance, bundle integrity, E0/E1 purity, convergence, artifact staging, and official grading all pass. Infrastructure failures are recorded separately and are not converted to score zero.

## Platform notes

No-model h1 provisioning and basic input-byte checks have been observed to work. Model-based remote runs have also exposed sandbox runtime permission/cache and artifact-pipeline issues. These are platform diagnostics, not model or method scores.

The repository therefore contains the protocol and validation harness, not a completed claim of final main-table results.
